AI Air Canvas

  • Developed an AI-powered Air Canvas application in Python that converts hand-drawn sketches into finished artwork using the Google Gemini generative AI API.
  • Implemented computer vision-based hand tracking to capture freehand sketches drawn in mid-air, translating hand movement into on-screen strokes.
  • Integrated the Gemini API to interpret sketch input and generate enhanced, styled artwork from minimal freehand input.
  • Designed the sketch-to-generation pipeline to bridge raw visual input with generative AI output, enabling touchless digital art creation.
  • Structured the application for extensibility, allowing future support for additional generative art styles and models.

Hand Gesture Controller
